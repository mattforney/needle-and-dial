# What each station's announcer says, recorded by tools/voices/package.py.
#
# A block per station: "== key voice frequency", the frequency as the announcer says it. Then a line per
# recording:
#   legal:   the top-of-hour ID. It gives the call letters followed straight away by the city of license,
#            in that order ("WHOX New York"), and the station's name and frequency ("Whodunit, six-forty"),
#            so the branding matches the sweepers'.
#   sweeper: everything else the station says about itself between programs or records. It gives the
#            station's name and frequency; call letters are optional, and mostly left out because the
#            names are long already.
# Write call letters as they look ("WHOX"); the renderer spells them out for the voice. Write numbers as
# words ("six-forty"). The renderer checks every line against these rules before recording anything.
#
# "pron:" sets how a word is said, in Kokoro's phonemes, where its own guess is wrong ("Bach" as "batch").
